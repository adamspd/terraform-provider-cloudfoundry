# cloudfoundry_org_quota_assignment (Resource)

Assigns an org quota to an org. Use this resource instead of the `orgs` attribute of `cloudfoundry_org_quota` when the quota and the org are created and destroyed together: the assignment is destroyed first, so the quota can be deleted before the org. Do not manage the same org with both this resource and the `orgs` attribute of `cloudfoundry_org_quota`.

An org always has exactly one quota. When this resource is destroyed, the org is moved to the `fallback_quota`.

## Example Usage

```terraform
terraform {
  required_providers {
    cloudfoundry = {
      source = "cloudfoundry/cloudfoundry"
    }
  }
}
provider "cloudfoundry" {}

resource "cloudfoundry_org" "my_org" {
  name = "my-org"
}

resource "cloudfoundry_org_quota" "my_org_quota" {
  name                     = "my-org-quota"
  allow_paid_service_plans = true
  total_memory             = 1024
}

# On destroy, the org is moved to the quota named "default", or to "fallback_quota" if it is set.
# The assignment is destroyed first, so the quota and the org can be deleted afterwards.
resource "cloudfoundry_org_quota_assignment" "my_org" {
  org   = cloudfoundry_org.my_org.id
  quota = cloudfoundry_org_quota.my_org_quota.id
}
```

## Schema

### Required

- `org` (String) The GUID of the org the quota is assigned to. Changing it creates a new assignment.
- `quota` (String) The GUID of the org quota to assign to the org.

### Optional

- `fallback_quota` (String) The GUID of the org quota the org is moved to when this resource is destroyed. If not set, the quota named `default` is used.

### Read-Only

- `id` (String) The GUID of the org. It is the identifier of this assignment.
